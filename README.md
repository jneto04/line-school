# Line School

**Nunca é tarde para aprender.** Aplicativo web de alfabetização para pessoas idosas (EJA), com aulas por sílabas, jogos, escrita com o dedo, voz em português e níveis que se desbloqueiam conforme o aluno avança.

Funciona no navegador do celular, tablet ou computador. No Chrome do Android, use "Adicionar à tela inicial" para instalar como app. Após a primeira abertura, funciona sem internet.

## Arquivos
- `index.html` — o aplicativo completo
- `manifest.json` e ícones — instalação na tela inicial
- `sw.js` — funcionamento sem internet

Projeto de pesquisa "Line School: Nunca é tarde para aprender".
